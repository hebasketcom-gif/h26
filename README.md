# Dr. Samala Sri Kavya — Medical Reviewer Portfolio

A premium, modern, single-page professional portfolio website for **Dr. Samala Sri Kavya** (She/Her), Medical Reviewer specializing in Dentistry to Drug Safety, Pharmacovigilance, and Clinical Research.

## 🌟 Live Preview
Built with Vanilla **HTML5**, **CSS3**, and **Vanilla JavaScript** for maximum performance, accessibility, and zero-dependency deployment.

## 🚀 GitHub Pages Deployment

This project is configured to run out-of-the-box on GitHub Pages.

1. **Upload to GitHub Repository**:
   - Push `index.html`, `style.css`, `script.js`, and `README.md` to your repository's `main` or `gh-pages` branch.

2. **Enable GitHub Pages**:
   - Go to your repository settings on GitHub: **Settings** > **Pages**.
   - Under **Source**, choose **Deploy from a branch** and select `main` branch `/ (root)`.
   - Click **Save**. Your site will be published at `https://<username>.github.io/<repo-name>/`.
