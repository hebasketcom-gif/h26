# Dr. Samala Sri Kavya - Professional Portfolio

> **Medical Reviewer | From Dentistry to Drug Safety | Pharmacovigilance & Clinical Research**

A high-end, responsive, accessible single-page professional portfolio website for **Dr. Samala Sri Kavya**. Built strictly using clean HTML5, CSS3, and Vanilla JavaScript with zero external frameworks or backend dependencies. Directly deployable on GitHub Pages.

---

## 🌟 Key Features

- **Vanilla HTML5/CSS3/JavaScript**: Pure client-side codebase. No React, Vue, jQuery, or build steps required.
- **GitHub Pages Ready**: Upload directly to any GitHub repository and enable GitHub Pages on the `main` branch root.
- **Light & Dark Mode**: Built-in theme switcher with smooth transitions and state persistence using `localStorage`.
- **Responsive Design**: Flawlessly optimized across 4K displays, desktops, tablets, and mobile devices with a custom animated mobile navigation menu.
- **IntersectionObserver Animations**: Scroll-triggered fade-ins, card reveals, progress bar updates, and active section menu highlights.
- **Accessible & SEO Optimized**: Includes semantic HTML5 tags, Schema.org `Person` JSON-LD structured data, Open Graph cards, Twitter metadata, and `prefers-reduced-motion` support.

## 🚀 How to Deploy to GitHub Pages

1. **Push to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Dr. Samala Sri Kavya portfolio"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   git push -u origin main
   ```

2. **Enable GitHub Pages**:
   - Go to your repository **Settings** tab on GitHub.
   - Click on **Pages** in the left sidebar.
   - Under **Build and deployment** -> **Source**, select `Deploy from a branch`.
   - Select `main` branch and `/ (root)` folder, then click **Save**.
   - Your site will be live at `https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/` in a few moments!
