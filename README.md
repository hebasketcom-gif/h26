# Dr. Samala Sri Kavya — Professional Portfolio

A premium, single-page professional portfolio website for **Dr. Samala Sri Kavya** (She/Her) — Medical Reviewer | From Dentistry to Drug Safety | Pharmacovigilance & Clinical Research.

## 🌟 Key Features

- **Medical & Research Visual Identity**: High-end healthcare, pharmaceutical, scientific, and editorial styling.
- **Responsive Architecture**: Fully optimized for 4K displays, desktop, tablet, and mobile devices.
- **Light & Dark Mode**: Built-in theme toggle with `localStorage` preference persistence.
- **Interactive Journey Timeline**: Seamless step-by-step presentation from Dentistry to Drug Safety.
- **Smooth Scroll Animations**: IntersectionObserver-powered reveal effects, parallax accents, and micro-interactions.
- **Accessible & SEO Ready**: Semantic HTML5 markup, ARIA roles, high contrast ratios, and Open Graph metadata.

## 🚀 GitHub Pages Deployment

This website is built using **pure HTML5, CSS3, and Vanilla JavaScript**.
It requires **no build step, no npm packages, and no backend configuration**.

To deploy on GitHub Pages:
1. Push this repository to GitHub.
2. Go to **Settings > Pages**.
3. Select the `main` branch and `/` (root) directory.
4. Click **Save**. Your site will be live in seconds!
