# Dr. Samala Sri Kavya - Professional Portfolio

A premium, modern single-page professional portfolio website for **Dr. Samala Sri Kavya** (Medical Reviewer | Pharmacovigilance & Clinical Research).

## 🌟 Overview & Aesthetics

Designed with a high-end medical and pharmaceutical aesthetic combining clean university typography, responsive glassmorphism navigation, dark/light theme switching, and interactive scientific particle visualizations.

### Key Sections
- **Hero**: Cinematic introduction with profile portrait, scientific canvas, and quick CTA buttons.
- **About**: Detailed career transition narrative from Dentistry to Medical Review and Drug Safety.
- **Professional Journey**: Interactive timeline showcasing milestones from clinical practice to global drug safety.
- **Core Expertise**: Highlighting Medical Review, Drug Safety, Pharmacovigilance, Clinical Research, Dentistry, and Healthcare.
- **Pharmacovigilance & Drug Safety**: Feature breakdown of safety monitoring and adverse event processing.
- **Clinical Research**: Evidence-based healthcare pillars and research orientation.
- **Transition Pathway**: Visual diagram illustrating the Dentistry → Medical Review → Drug Safety progression.
- **Professional Strengths**: Key competencies with scroll-triggered animations.
- **Research & Publications**: Future-ready structured publications container.
- **Contact**: Clean professional connect card with LinkedIn link and message form.

## 🚀 Deployment via GitHub Pages

This repository is completely static (`index.html`, `style.css`, `script.js`) and ready for immediate deployment on GitHub Pages:

1. Create a new repository on GitHub.
2. Push all files in this project to the `main` branch.
3. Go to **Settings** > **Pages** in your GitHub repository.
4. Under **Source**, select `main` branch and `/ (root)` folder.
5. Click **Save**. Your website will be live in seconds!

## 🛠️ Technology Stack
- **HTML5**: Semantic tags (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`) with Schema.org JSON-LD structured data.
- **CSS3**: Custom CSS variables, responsive grid/flexbox, glassmorphism backdrop filters, light/dark mode theme system.
- **Vanilla JavaScript**: Zero dependencies. IntersectionObserver scroll animations, interactive HTML5 particle canvas, theme persistence in `localStorage`, contact form validation.
